# 模拟一致性规则

## 必要免责声明

每次模拟都必须包含：

> 这是模拟，不是事实。

## 硬约束

- 没有证据时，不要改变人物的稳定性格。
- 不要改变已经发生的重大公共事件。
- 不要忽略地理、时代、经济条件、家庭约束、学校/工作约束或社会背景。
- 不要把遗憾改写成立刻成功的幻想。
- 不要用模拟逼迫用户联系某人、辞职、结束关系，或做医疗/法律/财务决定。

## 确定性标签

| 标签 | 含义 |
| --- | --- |
| `high_certainty` | 由事实、稳定约束和事件图强烈支持 |
| `medium_possibility` | 合理但依赖不确定的人类回应 |
| `low_certainty_imagination` | 仅用于反思的想象性场景 |

## 敏感主题

面对哀伤、创伤、疾病、家庭破裂、感情遗憾、霸凌或羞耻时：

- 放慢叙事节奏。
- 避免指责和道德评判。
- 避免“一切都有原因”这类语言。
- 提供稳定当下的支持和面向现实的下一步。
- 当用户表达自伤或严重痛苦时，建议寻求专业支持。

## Merge-back 规则

一个 branch 只有能把以下内容之一带回 `main`，才是有用的：

- 一个更温柔的理解。
- 一段用户可以自主选择是否进行的小对话。
- 一个边界。
- 一个告别仪式。
- 一个创作输出。
- 一个用户当前生活里可执行的实际下一步。

## 可信语义层边界

- Character、World、Memory、Event Graph 是领域建模结构，不等同于事实、回忆、理解、模拟。
- 事实层和回忆层可以支撑理解和模拟；理解不能自动升级为事实。
- 模拟情节不能写入事实或回忆层，也不能自动成为理解层。
- 用户明确确认后，系统可以保存一条受模拟启发的当前理解；该理解必须保留 `simulation_origin_id`，且不能把模拟情节描述成真实经历。
- 删除记录前必须展示直接依赖；导出不得覆盖现有文件；删除默认进入可恢复回收站。
