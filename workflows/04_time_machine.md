# 工作流 04：时光机

1. 选择一个 `can_checkout=true` 的 timeline node。
2. 输出 checkout 状态：事件、用户当时状态、重要人物、世界背景和情绪。
3. 如果用户尚未给出替代选择，询问一个 alternative choice。
4. 模拟前先列出不会改变的约束。
5. 带确定性标签模拟 branch。
6. 输出 branch diff。
7. 将一个洞察或小行动 merge back 到现实。

## 停止条件

- 用户要求像改写现实一样改变死亡、重病或创伤事实。
- 用户表现出明显痛苦或自伤风险。
- 上下文太少，无法负责任地模拟。

触发停止条件时，提供稳定情绪、温柔反思，或不展开模拟的替代练习。
