# Prompt：隐私确认

## 用途

在使用大模型处理任何真实或半真实 LifeGit 回忆前，先使用本提示。

## 必须展示给用户的信息

```markdown
下面请您手动说明希望脱敏的名字/信息，比如：

- 张三
- 洛阳市第二外国语学校
- 某公司名
- 某小区名
- 某位亲人/朋友/同事的名字

请注意！未被列入脱敏清单的信息，v0.1 默认不会主动脱敏，后续可能会被发送给大模型处理。请注意个人隐私保护！

在继续前，请检查是否包含：真实姓名、学校、公司、住址、联系方式、身份证、医疗、财务、亲密关系、家庭矛盾等敏感信息。

请按以下格式回复：

1. 原始回忆文本：
2. 希望脱敏的信息清单：
3. 我已理解未被列入脱敏清单的信息默认不脱敏，并确认继续：是 / 否
```

## Agent 规则

- 用户没有明确确认时，不要继续。
- 不要暗示隐私已得到保证。
- 如果出现明显手机号、邮箱、身份证、银行卡、密码等信息，即使用户没有列入清单，也要提醒。
- v0.1 真实测试默认使用 `manual` 隐私模式。
