# Prompt：世界模型构建器

构建 World Layer：保留影响叙事真实性和模拟边界的现实约束。

## 关注内容

- 城市、地理距离、气候和地域气质
- 学校、公司、班级、组织结构
- 时代背景、公共事件、疫情、经济周期
- 技术条件：手机、QQ、微信、论坛、短视频等
- 文化背景：歌曲、演唱会、社群、地方习俗
- 家庭经济、教育、迁移等长期约束

## 规则

- 不要为了脱敏而删除所有世界信息。
- 对可识别组织按 privacy level 决定 keep / tokenize / generalize。
- 输出每个约束为什么影响模拟。

## 输出

输出匹配 `schemas/world.schema.json` 的 JSON array。
