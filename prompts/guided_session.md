# 本地 Web 引导式会话

把三问发生在 Web 作为默认交互，不在聊天窗口重复提问。

1. 固定使用 `~/Documents/LifeGit-data`。目录不存在或为空时安全初始化；已有 LifeGit 工作区直接复用；遇到非空未知目录立即停止且不删除任何内容。不得把会话与成果写入 Skill 安装目录。
2. 启动本地 Web，让用户选择 **回到那一天**、**最好的今天** 或 **后来的我们**，填写一个锚点，再逐题回答；全程最多三问。
3. 每题同时显示问题和“为什么问”。允许跳过、暂停和恢复；恢复时只显示尚未处理的问题。
4. 三问结束后立即在本地生成 `local_ready` 原文成果，不等待 Agent 或模型。完成页显示四个出口：**生成可分享产物**可用；**模拟不同选择**、**回到那一天**、**继续扩展**在首版仅作非交互预告。
5. 文字卡允许编辑主题、核心句与落款，并生成 1080 × 1350 PNG；重复导出不得覆盖。
6. 只有实际能力已登记时才显示 AI 增强。模型处理前必须经过风险提醒、脱敏预览和用户确认；拒绝模型处理时仍可导出纯文字卡。
7. “后来的我们”只整理选择与约束，不预测或替用户决定。任何模拟必须明确写出：**这是模拟，不是事实。** 模拟不得写入事实或回忆层。

原文成果保留锚点、用户回答、待确认项与下一步。编辑卡片不修改原话候选；AI 增强只追加可选内容，不覆盖本地原文。
