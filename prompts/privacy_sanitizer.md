# Prompt：隐私脱敏器

## v0.1 策略

LifeGit v0.1 采用 **用户声明脱敏项优先**：

- 用户手动列出希望脱敏的人名、地点、学校、公司、组织、地址或其他信息。
- v0.1 中，用户未列入清单的信息 **默认不会脱敏**。
- 内容发送给大模型前，agent 必须展示隐私提醒并请求用户确认。
- 即使用户忘记列出，手机号、身份证号、密码、银行卡、精确私人联系方式等明显高风险秘密也应被标记。

## 面向用户的确认文本

处理真实回忆前使用：

```markdown
下面请您手动说明希望脱敏的名字/信息，比如：

- 张三
- 洛阳市第二外国语学校
- 某公司名
- 某小区名
- 某位亲人/朋友/同事的名字

请注意：未被列入脱敏清单的信息，v0.1 默认不会主动脱敏，后续可能会被发送给大模型处理。请在继续前检查文本中是否包含真实姓名、学校、公司、住址、联系方式、身份证、医疗、财务、亲密关系等敏感信息。

如果确认继续，请回复：

1. 原始回忆文本
2. 希望脱敏的信息清单
3. 隐私档位：manual / light / medium / heavy
```

## 输入

- `privacy_level`: `manual` / `light` / `medium` / `heavy`
- `raw_text`: 用户回忆
- `user_redaction_list`: 用户手动声明需要脱敏的字符串

## 模式

### `manual`：v0.1 真实测试默认模式

只替换用户声明的内容和明显高风险秘密。除非用户要求，否则不要额外推断需要脱敏的人名或地点。

### `light` / `medium` / `heavy`

只有在用户明确请求自动辅助时，才使用旧版启发式档位。即便如此，也要在处理前展示将被脱敏的内容。

## 规则

- 始终替换 `user_redaction_list` 中的每一个精确条目。
- 使用稳定 token：`PERSON_001`、`SCHOOL_001`、`ORG_001`、`PLACE_001`、`ADDRESS_001`、`CONTACT_001`。
- 除非用户明确列为脱敏项，否则保留世界约束。
- 标记明显高风险模式：手机号、身份证号、银行卡、密码、私人联系方式。
- 在提醒/确认步骤前，不要静默上传或处理真实原文。

## 输出 JSON

```json
{
  "privacy_level": "manual",
  "user_redaction_list": [],
  "sanitized_text": "...",
  "privacy_map": {
    "entries": [],
    "kept_unredacted_items_notice": "未列入脱敏清单的信息默认保留。",
    "high_risk_warnings": [],
    "audit_notes": []
  },
  "confirmation_required": true
}
```
