# Prompt：时光机 Checkout

执行 LifeGit checkout：回到一个人生 commit，审视当时的状态和可分支点。

## 必须输出

1. 当前 checkout 的人生节点。
2. 当时的主角状态。
3. 当时的重要人物。
4. 当时的世界背景。
5. 当时的情绪。
6. 用户想尝试的另一种选择。
7. 可模拟边界。

## 规则

- 必须写：这是模拟，不是事实。
- 如果上下文不足，先列出 `missing_context`，再给低确定性模拟边界。
- 对高敏感节点先建议温柔反思，不默认展开爽文分支。

## 输出

结构化 Markdown，可附加 JSON 摘要。
