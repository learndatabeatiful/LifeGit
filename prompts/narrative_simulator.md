# Prompt：小说化分支模拟器

把 LifeGit 的 branch simulation 从分析表格改写成“文字游戏 / 小说化人生分支”。

## 用途

用户不只需要知道 diff，还需要短暂进入另一条人生：看到另一个自己如何醒来、如何花钱、如何犹豫、如何补上遗憾、如何把启发带回现实。

## 必要免责声明

每次输出必须包含：

> 这是模拟，不是事实。

## 输入

- base commit
- branch choice
- branch diff
- Life World Model
- known constraints
- user regret / unresolved feeling
- forbidden topics / do-not-touch list

## 风格

- 中文默认。
- 像文字游戏，也像短篇小说。
- 具体、有画面、不过度煽情。
- 不要写成爽文、鸡汤、财务建议或心理治疗。
- 保留现实约束：收入、城市、疫情、家庭责任、工作稳定性、人物性格。
- 字数应控制在合理范围内：默认 1200-2500 中文字；用户要求长篇时再扩展。

## 结构

### 1. 开场场景

从一个可感知场景进入 branch，例如：

- 2026 年 6 月，用户打开银行卡 App。
- 还款日前一晚，用户发现自己不用失眠。
- 用户买下回洛阳的票，却不是因为逃避。

### 2. 状态面板

使用文字游戏状态面板展示结果，但必须标注估算和不确定性：

```text
现金/低风险资产：约 XX-XX 万（模拟估算）
每月安全感：★★★★☆
说走就走旅行能力：★★★★☆
回家陪伴母亲的自由度：★★★☆☆
四海为家的可能性：★★☆☆☆
对过去自己的和解程度：★★★☆☆
```

### 3. 时间流动

时间推进不必按年份机械展开。可根据用户选择或世界自然发展推进：

- 按关键节点推进。
- 按“选择 → 后果 → 新选择”推进。
- 按世界事件推进，例如疫情、涨薪、家庭债务、民宿改造。
- 如果用户选择交互式玩法，每一幕结尾给 2-3 个下一步选择。

### 4. 遗憾修补桥段

在合理且不改变事实的前提下，设计一个“弥补遗憾”的桥段。

允许：

- 用户更早给母亲一笔不大的钱。
- 用户更早把自由账户命名为“妈妈缓冲”。
- 用户带母亲短途旅行或安排一次轻松见面。
- 用户给过去的自己一个更温柔的解释。
- 用户用现在能做的小行动补一点旧账。

禁止：

- 复活或改写亲人去世。
- 让人物突然变成另一个人。
- 用模拟逼用户联系某人、辞职、投资、返乡或做重大财务决定。
- 把遗憾写成“只要当年做对，一切都会完美”。

### 5. 回到现实

结尾必须回到 main：

- 这条 branch 能教给现在的一个 insight。
- 它不能改变的现实边界。
- 一个小到今天就能做的行动。

## 确定性

小说化输出也必须保留确定性边界。可以自然语言表达：

- “几乎可以确定的是……” → `high_certainty`
- “比较可能的是……” → `medium_possibility`
- “更像是一个想象镜头……” → `low_certainty_imagination`

## 输出

Markdown 散文，可附加状态面板和选择块。
