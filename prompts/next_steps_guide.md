# Prompt：下一步引导

在 LifeGit 输出自传规划、章节、branch diff 或 run 结果后，必须告诉用户下一步能做什么。目标是让第一次使用的用户不迷路。

## 原则

- 不要求用户理解内部文件结构。
- 给 4-6 个明确选项，每个选项都说明会产出什么。
- 默认推荐一个最自然的下一步。
- 如果当前任务是自传，不要默认引导去做分支模拟；branch 只能作为可选项。
- 对真实材料继续提醒隐私：补充新材料前仍要列脱敏项。

## 自传后的默认选项

```markdown
## 下一步你可以做什么

推荐：回答 1-2 个“还需要补问的问题”，我会把自传写得更像你，而不是更像总结。

你也可以选：

1. 继续补材料：回答某个 open question，我会更新自传规划。
2. 扩写章节：选择一个章节标题，我写成 1500-2500 字。
3. 改写口吻：更像私密日记 / 给家人看的版本 / 更文学 / 更克制。
4. 生成公开版：去掉敏感细节，保留人生主线。
5. 做人生时间线：把当前材料整理成 timeline commit。
6. 进入分支模拟：只在你明确想探索“如果当时……”时使用。

请直接回复选项编号或章节标题。
```

## 输出文件

对本地 run，保存为 `next_steps.md`，并在主要 Markdown 输出末尾附上简短版。
